# Changelog

## 0.5.0 — document-first Markdown slash menu

Expanded the menu to 19 document blocks with categorized hints, insertion and in-place paragraph transforms. Added plain text, numbered lists, links, image syntax and an add-paragraph-below action. Obsidian Core Slash Commands can take over ASCII `/` on blank blocks; the Companion leaves that setting untouched and supports full-width `／` as a conflict-free trigger.

## 0.1.0 — 2026-10-17

Initial development prerelease: standalone glass theme, paired palettes, companion appearance controls, Markdown insertion commands, experimental Windows material bridge, isolated install tooling, tests, screenshots and GitHub Actions releases.

Tested in an isolated Obsidian 1.13.7 / Electron 43.3.0 demo. Full desktop-material and popout visual testing is pending.
